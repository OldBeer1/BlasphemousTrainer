# 神之亵渎修改器 v0.6.3：使用说明

适用：本机《神之亵渎》一代 4.0.67-DLC3，Steam Build 20206233，普通新游戏。更新：2026-09-30。

当前已实现十项持续功能、**防御专项三选一（关闭／减伤 25-90%／免扣血）**、**计时暂停两项（菜单暂停／自由冻结）**、正负金额调整、统一面板、操作提示、键盘及手柄操作。作弊记忆、负数减钱及余额预览已实现。

## 现在怎么用

安装后正常启动游戏，进入普通新游戏存档，按 F1（原配置改过则用原按键）。不需单独运行控制软件。界面为**功能／扩展功能／设置**三个页签，两块条目数量接近：功能放生存与移动（无限热情、血瓶不消耗、防御模式、移动速度、跳跃），扩展功能放输出、经济与计时（剑击倍率、祷文倍率、击杀赎罪之泪倍率与加减钱、菜单暂停计时、自由暂停计时），设置页放改键与显示。

- 生存与战斗：普通战斗锁血、无限热情、血瓶不消耗、剑击伤害 1–10 倍。无限热情不解锁祷文，血瓶功能需至少已有一瓶。
- 防御专项：防御模式三选一——关闭／减伤／免扣血。减伤档位 25%、50%、75%、90%，作用于原始伤害层（元素抗性与防御结算之前），实际掉血减少不低于所选档位；免扣血沿用原“锁定生命”的状态和快捷键；页面只保留一个防御模式入口，仅普通受击，不防尖刺、坠落、剧情死亡。默认关闭，换图保留本次选择，退主菜单与“全部关闭”恢复关闭。**减伤模式与免扣血都参与作弊记忆**：开启记忆后按上次选择恢复，其中免扣血就是“锁定生命”，与减伤互斥、以“锁定生命”优先；减伤档位属于偏好，始终保存。
- 成就与计时：游戏内时长用真实运行秒数累加，暂停游戏和开菜单都不会让它停下。**菜单暂停计时**在背包、地图或暂停画面打开期间不计入时长；**自由暂停计时**开启后完全停住，直到手动关闭。两者共用同一份已排除时间，“成就与计时”分组会显示当前游戏计时（时:分:秒）和累计已排除时长。AC44「Bronze Medal」（3 小时内穿越三之桥铜门）按这个时长判定，因此这两项只在判定前开启才有意义。排除只作用于开关生效之后的时间，不会减少进档时已经累计的时长；已经排除的部分不会因为关闭开关而还回去，也不会写入作弊记忆之外的其他状态。
- 片头跳过：默认跳过启动 logo 视频，并让标题画面自动进入主菜单（`Interface.SkipIntro`，默认开启）。标题画面仍会完成音频库加载与核心预初始化，不会破坏声音。
- 扩展：手动增加 1,000／10,000 或输入正整数加钱、负整数减钱，并预览调整后余额；击杀奖励 1–10 倍；移动 1–2 倍；普通起跳 1–1.5 倍；部分祷文伤害 1–10 倍。
- 祷文覆盖仅限爬行光球、垂直光柱、毒云对应的已核验来源路径；其他祷文、反弹、部分特殊 Boss 伤害链不保证覆盖。收入倍率仅击杀奖励，不增强物品／任务收入。
- 开关独立，“记住作弊开关”默认关闭；关闭时进档全关。开启记忆后，本机所有受支持普通存档在玩家就绪后恢复最近的持续开关、防御模式与倍率，并显示恢复项数；完整清单见 BepInEx/LogOutput.log。换图和重生保留本次开关，不重复恢复提示。全部关闭不撤销已加的钱或已造成的伤害。
- 上下选择、Enter 执行，倍率行左右调整；鼠标滚轮滚动。键盘导航仅在面板接管游戏暂停时启用。
- 设置页可改键／清除可选键、检查当前游戏绑定、调整缩放。倍率、按键、位置和缩放保存；持续功能开关仅在记忆开启时保存。关闭记忆保持本次会话效果，但下一次进档全关。
- 手柄确认／返回／翻页采用游戏映射，十字键或左摇杆导航。单按右摇杆（R3）打开面板，不需要组合键或长按；返回键关闭。旧组合键配置不再使用，未识别 R3 时仍可用 F1。
- 接管暂停时隔离游戏输入；关闭面板后松开按键与导航摇杆约 0.12 秒再恢复游戏。数字键盘“完成”只填写，另点“执行金额调整”才加减钱，± 按钮切换正负号。

加减钱会影响后续存档；先用测试存档。总量限制到游戏上限与 9,999,999 中较低者，超限添加、余额不足整笔拒绝；允许恰好扣到 0。加减钱不受收入倍率影响，永不因读档或记忆恢复重复执行。锁血不防尖刺、坠落、剧情死亡。不修改原游戏 DLL、不永久修改最大生命和移动参数。

## 三步安装

1. 退出游戏，把 `BlasphemousTrainer-0.6.3.zip` 解压到普通文件夹，双击 **安装工具.exe**。不要只从压缩包内打开 EXE；其旁的 Backend.ps1、release.json 与 payload 必须完整保留。
2. 工具会查找 Steam 默认与额外库；多个结果时选择目标，找不到则点“选择游戏”并选择 Blasphemous.exe。核对显示的完整目录，可先点“检查／预览”。
3. 点击“安装／更新”。完成后关闭工具，正常启动游戏，进入普通新游戏存档后按 F1（保留旧配置时使用原按键）。不需要保持安装工具运行。

运行要求：Windows、Windows PowerShell 5.1、.NET Framework 4.5 或更高；本机已具备。无需安装开发 SDK；不要求管理员权限。安装器未做代码签名。首次准备 BepInEx 需要联网，固定版本下载校验完成后可以使用本地缓存。

只支持 [开发与维护](docs/开发与维护.md) 中明确的本机游戏文件指纹。未知版本、加载器冲突、同名插件内容不明、目录链接、游戏运行中，均停止操作并说明原因。

## 文件与备份

- 插件：`BepInEx/plugins/BlasphemousTrainer/BlasphemousTrainer.dll`。
- 设置：`BepInEx/config/local.blasphemous.trainer.cfg`。
- 图形安装清单：`BepInEx/config/local.blasphemous.trainer.install.json`。
- 更新／卸载备份：游戏目录 `TrainerBackups`；已保留本次更新和上一稳定版本的必要回滚资料，过时开发期备份已清理。
- 存档备份：`%LOCALAPPDATA%/BlasphemousTrainerBackups` 下独立目录，包含校验记录。安装会备份发现的默认存档位置；工具也有独立备份按钮。
- 加载器缓存：`%LOCALAPPDATA%/BlasphemousTrainerInstaller`。

文件检查和复制成功不等于游戏加载／玩法验收通过。安装清单不会因为复制成功而把 RuntimeVerified 改成 true。

## 卸载

退出游戏，打开安装工具，选择相同目录，点击“卸载本插件”。默认保留配置；需要重置配置时勾选对应选项。卸载会先备份被移除的插件和配置，按哈希检查已安装插件，不删除整个 BepInEx，不动存档和其他 MOD。

共享加载器默认保留。本版图形工具不提供一键删除共享加载器，避免破坏其他 MOD。卸载后若需要恢复本修改器，重新安装即可。

若忘记面板键：退出游戏，在配置文件中将 `PanelKey` 设为 `F1`。设置页面也有恢复默认按键按钮。默认可选功能快捷键均为 None。

## v0.6.2 本次优化与复测

七项优化已完成：计时关闭与保存修正、状态流程自动测试、防御入口去重、小屏提示适配、文档整合、功能及版本统一定义、手柄映射缓存。防御仍只有减伤和免扣血。旧防御提案已归档，不再分发；此前用户完成的旧版测试记录保留，本次改变仍需以下实机复测。

1. **暂停计时再关闭**：进普通测试存档，扩展页记下“当前游戏计时”。只开“自由暂停计时”，关闭面板活动约 20 秒，回来读数应基本不变；关闭两个计时开关，再活动约 20 秒，读数应只增加后面这 20 秒，不能突然补回前面的 20 秒。“全部关闭”后也应如此。
2. **背包／地图与保存**：仅开启“菜单暂停计时”，分别打开背包、地图约 20 秒，游戏计时应基本不增；关菜单正常活动约 20 秒应增长。再开自由暂停、等待 20 秒后关闭两项，到存档点保存、退主菜单重进，时长不得补回已排除部分或再次扣减。存档点路上未冻结的时间正常计入；同一位置连续保存再读档也不应重复扣时。换另一个普通槽，原槽的排除量不能扣在新槽上。
3. **防御与记忆**：功能页只应有一个防御入口，依次切换关闭、减伤、免扣血，找同一普通敌人受击观察减伤／免扣血。原锁血快捷键若已配置，仍切换免扣血，并同步面板。开启记忆，分别记住减伤和免扣血后退主菜单、重启游戏进档，各恢复一次；点击全部关闭后重进应全关。关闭记忆不会撤销本次效果，但下次进档不恢复。
4. **提示与输入取消**：用窗口模式降低到 1280×720（有更低分辨率可补测），连续改倍率、开关、进档恢复，提示应留在屏幕内；空间不足时优先显示最新消息，长消息缩略后可看日志。鼠标按下按钮后移走／关闭面板、改键时按 Esc、数字键盘点取消，都不得误执行金额调整或留下游戏输入阻断。
5. **手柄**：R3 单按开面板，确认、返回、导航、翻页应正常。面板打开时断开重连手柄，先松键再操作，不应误确认。游戏内修改确认／返回映射后再次打开面板应使用新映射；也可在设置页点“刷新手柄映射”立即刷新。通常自动重建间隔不超过 0.5 秒，换设备、换场景及退出游戏改键录制时立即失效。

本次工程构建、规则及流程测试已通过；真实游戏画面、存档文件往返及手柄设备仍由上述实机复测确认，不将旧版“已测”标记套到新改动上。
## v0.6.3 界面风格调整

以现有面板为基础，参考布局示意图的深色暗金风格，不逐项复制设计图。保留“功能／扩展功能／设置”三栏、现有功能分类、两个加钱预设、负数输入、作弊记忆及全部操作方式。没有新增设计图中的装饰侧栏或负金额预设按钮。

- 标题、页签、分组标题和细分隔线采用暗金色；主体保持深灰背景。
- 功能名称在左，倍率的 −／数值／+ 与状态开关排在同一行；开关显示开启／关闭／等待／不可用。防御仍是一个关闭／减伤／免扣血入口。
- 记忆开关置于内容顶部；滚动只影响中间内容。全部关闭、操作提示和关闭面板保留在固定底栏。
- 紧凑按钮用暗金描边表示键盘／手柄选择，不把额外箭头挤进倍率数值或开关文字。
- 金额输入、数字键盘入口和执行按钮集中成行；执行按钮显示增加／减少及金额，计算和执行规则不变。
- 数字键盘居中独立显示，屏幕较矮时只滚动数字区域，取消／完成固定可见；原有预览、±、清空、退格和 15 项导航保留。

本次实机只需重点复测：三个页签切换、鼠标指针及点击、倍率 ± 与左右键调整、手柄焦点与滚动、缩放后文字是否完整、数字键盘取消／完成是否可达，以及底栏按钮是否始终可见。玩法补丁未变，旧计时与防御测试方法仍适用。工程检查通过不代表已观察过 Unity 实际画面。
