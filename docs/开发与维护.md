# 开发与维护：神之亵渎修改器 v0.6.3

合并原任务书、构建入口、兼容性记录、接口映射和第三方依赖。功能使用见 [使用说明](../README.md)；原开发方案已并入第 6 节。

当前版本 v0.6.3（2026-09-30）。上一版实机测试由用户确认完成（2026-09-28）；本次七项优化已完成工程验证，新增实机复测见 README。

## 1. 当前开发约束

- 保留 C#、net35、BepInEx 5.4.23.5 及配套 HarmonyX；不升级游戏运行时或擅自引入依赖。
- 只支持第 3 节兼容性记录中的本机指纹、普通 NEW_GAME；特殊模式、其他 MOD 组合和未知版本不推断为兼容。
- 倍率、位置、缩放和按键继续保存；持续开关仅在记忆开启时保存。换图与重生保留会话状态；主菜单关闭实际效果但不覆盖持久记忆，重新进档后按记忆选项恢复。
- 安装／更新先检查游戏退出和文件归属，备份存档及旧文件；卸载默认保留配置、共享加载器、其他 MOD 和存档。
- 安装工具与开发维护共用 Backend.ps1；过时的探针部署脚本已移除。
- 发布包不包含游戏 DLL、游戏资产、反编译源码、存档或 SDK。
- 新功能需编译、相关规则检查与接口核验；工程通过不替代游戏内确认。

## 2. 构建、检查与目录

PowerShell 中从 TrainerSource 运行：

```powershell
.\scripts\Build.ps1
.\scripts\Test-Core.ps1
.\scripts\Package.ps1
.\scripts\Test-Installer.ps1
```

- src/BlasphemousTrainer：插件入口、基础补丁、扩展补丁、纯数值规则、真实接口校验。
- installer：中文 Windows Forms 工具与唯一安装后端。
- tests：数值边界测试；安装脚本在隔离目录用假存档测试，不修改真实游戏或存档。
- docs：当前安装、兼容性、接口与依赖说明。
- .tools、.downloads：当前构建／安装测试仍使用的工具与校验下载缓存，不分发。
- .work：可重建的临时测试目录；旧反编译、测试夹具和打包源码副本已清理，打包后自动移除本次源码暂存目录。
- artifacts：当前交付／整理记录，不属于发行包。必要回滚资料位于游戏目录 TrainerBackups，用户目录中的存档备份保留。

游戏参考程序集保持 Private=false；构建只输出插件 DLL。Windows PowerShell 5.1 使用的中文脚本采用 UTF-8 BOM，避免 ANSI 误解析。

## 4. 接口与实现边界

### 本阶段界面与手柄

- PanelController 读取玩家 0 所属 Joystick 的实际 ControllerMap／ActionElementMap，再以物理 element identifier 读取控制器；不写死 Xbox 物理按钮编号，不改原映射。
- 本地 RewiredConsts.Action 核验：UI_Horizontal 48、UI_Vertical 49、UI_Submit 50、UI_Back 51、Inventory_Left 28、Inventory_Right 29；普通移动轴 0、4 作为导航补充。
- PanelInputGate 独立 Harmony owner 隔离玩家 0 的 GetButton*/GetAnyButton*/GetNegativeButton* 布尔读取及游戏使用的轴读取；只在本面板拥有输入／等待松键时生效，原始 Controller 读取留给面板。接管失败则不启用手柄入口，原鼠标机制保留。
- 关闭后在原暂停和输入阻断仍有效时等待松键约 0.12 秒；场景／模式退出及失焦时释放本插件拥有的阻断，保留其他阻断。
- 持续功能及金额提示由界面包装层读取实际结果后产生；不改既有剑击、祷文、击杀收入和移动补丁。

来源为本机固定指纹的 Assembly-CSharp.dll 和 Assembly-CSharp-firstpass.dll。临时反编译副本已清理，需要时可用保留的 ILSpy 重新只读分析；游戏程序集不分发。以下接口存在与指定调用点数量已做自动检查。

### 基础功能

| 功能 | 类型／入口 | 实现与副作用边界 |

| 无限热情 | Gameplay.GameControllers.Penitent.Abilities.PrayerUse.get_CanUsePrayer(): bool、OnUpdate(): void、StartUsingPrayer(Framework.Inventory.Prayer): void | 在已确认调用点替换资源读取和扣费，每个入口预期 1 处；只作用当前玩家 Fervour，不修改最大值或祷文解锁 |
| 血瓶不消耗 | Gameplay.GameControllers.Penitent.Abilities.Healing.Heal(): void | 4 个 VariableAttribute.set_Current 调用点仅对当前玩家 Flask 的减量拦截，其他属性照常 |

### 扩展功能

| 功能 | 精确入口 | 范围和数据流 |
|---|---|---|
| 手动加钱 | Framework.Managers.SkillManager.AddPurgePoints(float): void | 先校验带符号非零十进制整数、余额下限和上限，再调用原游戏接口；VariableAttribute.Current 的变化事件通知 HUD。接口不调用 GetPurge，因此不会被击杀收入倍率再次放大 |
| 击杀收入倍率 | Gameplay.GameControllers.Penitent.Penitent.GetPurge(Enemy): void | 仅此方法内 1 处 VariableAttribute.set_Current 替换为 SetReward。对扣除前余额和计算结果的正差额乘倍，保留原游戏的装备、罪孽和处决奖励计算；不 patch 全局 setter |
| 普通移动 | CreativeSpore.SmartColliders.PlatformCharacterController.Update(): void（firstpass） | 1 处 get_MaxWalkingSpeed 和 2 处 get_HorizontalMovingAcc 改为受控读取；只有当前玩家、Ready、开关开启时乘 1–2。不改字段、不改 Time.timeScale、不存旧实例基准 |
| 普通起跳 | 同一 Update 中 1 处 get_JumpingSpeed | 只有当前玩家、Ready、开启时乘 1–1.5；不改特殊墙跳或动画方法，不永久保存跳跃参数。已经在空中的物理速度不会因关闭被强行重置，下一次起跳恢复 |

| 池化生命周期 | Framework.Managers.PoolManager.ObjectInstance.Reuse(Vector3, Quaternion): void | 激活对象前清除旧标记；仅在上述创建作用域内绑定当前玩家。重用给敌人时清掉归属，旧玩家引用不匹配时不增强 |
| 祷文伤害 | EnemyDamageArea.TakeDamageAmount(Hit): void | 来源对象或其父对象上有本插件创建的有效标记、归属当前玩家、目标是 Enemy、非剑击作用域时才乘倍；仅改本次 Hit，持续效果关闭后不继续使用增强数值 |

其他祷文（含召唤守护者、多重射击等）未纳入白名单；有独立受伤逻辑的 Boss 不能以普通敌人测试推断覆盖。说明中的“爬行光球”“光柱”“毒云”是效果路径描述，不假定本地化显示名称。

### 状态、输入、设置

- Ready：Core.ready、当前 Penitent 非空且存活、有生命、普通 NEW_GAME、LogicStates.Playing、场景已就绪且非排除场景 D24Z01S01。
- 不在玩家缺失时清除 Enabled；效果函数动态引用当前玩家。主菜单 OnEnterMenuMode 清空，切 activeScene 仅关闭面板。
- 暂停与输入：游戏 InputManager.SetBlocker 和 LogicManager.PauseGame；只恢复本插件持有的暂停／输入状态。光标由 Unity Cursor 接口显示，不改游戏调试开关。
- 按键检查：读取 ReInput.players.GetPlayer(0).controllers.maps.GetAllMaps(ControllerType.Keyboard) 的 AllMaps／keyCode；读取失败标未核验。不会尝试修改游戏绑定。
- 改键录制仅允许关卡内面板已接管暂停时使用；新键释放前不执行快捷动作，内部重复和保留导航键拒绝，游戏正在录制按键时不监听插件快捷键。
- IMGUI 只收集动作，Update 执行；文本输入、失焦、录制期间抑制快捷动作；只响应按下沿。
- 每项功能独立 Harmony owner。加载时验证目标方法和调用点数；异常仅禁用对应功能。未知任一受支持游戏程序集指纹时不安装玩法补丁。

### 上限

手动加钱后总量不超过 min(游戏 CurrentMax, 9,999,999)，非零整数解析接受前导 +／-，不接受空格、指数、小数和溢出；余额不足整笔拒绝，允许扣到零，超插件上限已有余额允许合法减钱，不能精确表示的浮点金额拒绝；没有直接改存档。击杀倍率只放大正增量并限制增强后余额；已有超限余额不主动回写降低。两种伤害倍率均限制为 1–10，单次本插件处理后的 DamageAmount 不高于 1,000,000，实际伤害还受游戏防御与整数取整影响。

- 开启键不能顺带确认；关闭后等待按键释放约 0.12 秒再恢复游戏输入。未接管游戏暂停时仅鼠标操作。

### 6.2 记忆状态与持久化约定

| 情况 | 预期行为 |
|---|---|
| 打开记忆选项 | 立即保存此刻的持续功能开关；后续开关变化继续更新记忆 |
| 开启／关闭某项作弊 | 本次会话立即更新；记忆开启时同步保存成功后的状态 |
| 返回主菜单 | 停止实际作弊效果，保留记忆记录；不得把菜单清理产生的全关状态覆盖记忆 |
| 重新进入存档 | 指纹、接口和玩家状态通过检查后恢复可用功能，并显示一条恢复提示 |
| 完全退出游戏再启动 | 启动时先不作用于主菜单；进入受支持存档后再恢复 |
| 普通换图、传送、死亡重生 | 延续本次会话开关，不反复重放配置、不重复弹“进入存档恢复”提示 |
| 点击全部关闭 | 当前全部关闭；若记忆开启，同时保存“全部关闭”，下次不得重新打开旧功能 |
| 关闭记忆选项 | 当前正在使用的功能不突然关闭；清空保存的开关记录。下一次返回主菜单再进入或重启后默认全关 |
| 关闭后重新开启记忆 | 以当前会话的开关重新建立记录，不恢复过期记录 |
| 未知游戏版本、特殊模式或接口不兼容 | 不强行恢复，不绕过现有保护；提示原因，保留合法记忆以便之后进入受支持模式 |

### 6.3 恢复与保存约束

- 区分“用户想保留的状态”和“当前游戏允许生效的状态”。加载期间玩家对象为空，不等于用户关闭了功能。
- 区分“用户全部关闭”与“返回菜单暂停效果”，不能继续共用一个会清空持久记录的动作。
- 恢复通过明确的 SetEnabled 状态设置，不使用 Toggle 反转；同一加载过程重复收到事件也不会反向关闭。
- 识别一次新的存档进入过程；不能把每一次 Ready 从 false 变成 true 都视为新读档。
- 状态和配置只在发生变化时保存，不逐帧写盘。保存失败时保留内存状态并显示实情。
- 原配置升级后保留原有倍率／按键；没有新字段时记忆默认为关闭。忽略未知功能标识，数值继续做范围检查。
- 自动恢复完成后再显示汇总，不在加载一开始就提前报告成功；玩家尚未就绪时等待，不抢着改数值。


### 6.4 金额与游戏接口约束

- 使用原游戏 AddPurgePoints 资源接口和 HUD 事件，不直接编辑存档；正负增量都不经过击杀收入倍率补丁。
- 非零十进制整数，可带一个前导 + 或 -；当前拒绝空格、小数、指数、分隔符、NaN、Infinity、溢出。
- 不足余额与超过上限整笔拒绝；恰好扣到 0 合法；已有超插件上限余额允许合法减少，不主动重置余额。
- 不加勾选框或逐笔确认；数字键盘完成只填文本，取消不改金额，执行时重新读取余额并校验。
- 以宽数值检查结果，最小负整数不得直接在 int 内取绝对值；允许浮点资源不足 0.01 的舍入差，大整数精度丢失必须拒绝。
- 游戏版本指纹、祷文来源归属和特殊模式保护保持原范围，不扩大其他祷文或特殊 Boss 兼容承诺。

### 计时基线与成就范围

实际游戏路径：AC44Checker.Start → GetCurrentTimePlayedForAC44 / 60 < 180 → GetCurrentTimePlayed - TimeAtSlotAscension → TimeStored + Time.realtimeSinceStartup - LastTimeStored。两个 timer 开关共用一个排除量，不能把同一帧扣两次，不使用 Time.timeScale，不改成就触发器、不追回启用前时长。

GetCurrentPersistentState 内联读取实时钟，所以必须同时修正读取值和 PersitentPersistenceData.Time。已校正的存档在 isloading=true 的 SetCurrentPersistentState 与 ResetPersistence 建立新基线；isloading=false 不清零。关闭开关与全部关闭只停止今后的排除，保持此前排除的结果。菜单状态读取异常仅停止本次会话的菜单采样，自由冻结仍可工作；下次加载重置采样故障状态。

- FeatureCatalog.cs：功能登记表；数组下标和持久 ID 不重排，旧配置不迁移、不删除。页面隐藏 life 的重复按钮，不移除功能和快捷键。
